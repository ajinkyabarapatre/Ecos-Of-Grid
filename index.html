Initialize Sequence

The grid has been silent for centuries. Each level, an echo lights a path — watch carefully, then retrace the exact route before the trap resets.

  • Click or WASD / Arrows to step on tiles.
  • Step out of order and a trap fires — losing a life.
  • Clean & fast runs earn score multipliers.

How to Play

  1. WATCH — Cyan tiles light up one by one. Memorize the order.
  2. RECALL — Click tiles (or use WASD / Arrow keys to move a cursor) in the same order. Correct steps turn amber/gold.
  3. SCORE — Earn Level × 100 per correct step. A flawless run multiplies score by 1.5×; finishing recall quickly adds a speed bonus.
  4. LIVES — Three lives per run. Lose them all and the protocol resets.
  5. PROGRESSION — Levels 1–3 use a 3×3 grid (4-step sequence). Levels 4–7 use a 4×4 grid (6-step sequence). Levels 8+ use a 5×5 grid (8+ steps, faster timing).
